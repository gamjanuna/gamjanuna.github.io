세금 정보는 선택 · 가입 환영 크레딧 $300은 Gemini API 제외(충전 필요) · 결제 계정 목록이 뜨면 새 결제 계정 추가 클릭

문제 해결

키 등록

키 화면이 안 보임왼쪽 메뉴 API 키 클릭

키를 만들 권한이 없음개인 구글 계정으로 로그인

‘구글이 모르는 키입니다’복사 아이콘으로 다시 복사 > 붙여넣기

추출 중 멈춤

‘오늘 무료 사용량을 다 썼습니다’한국 시간 오후 5시(여름 오후 4시) 이후 이어서 추출, 또는 구글 충전

‘충전 잔액이 없거나 결제 한도에 걸려 멈췄습니다’구글 충전 > 큐쏙(Qssok) 앱 > 문제 DB > 이어서 할 시험지

충전 잔액이 남아 있는데 멈춤

‘오늘 쓸 수 있는 구글 AI 한도를 다 썼습니다’구글 하루 한도 · 충전으로 해제 안 됨 · 한국 시간 오후 5시(여름 오후 4시) 이후 이어서 추출 · 비율 제한 화면 ↗의 RPD 칸에서 확인

‘이번 달 구글 AI 지출 상한에 닿았습니다’본인이 설정한 월 지출 한도 도달 · 지출 화면 ↗ > 지출 한도 수정 클릭 > 금액 올리기 > 큐쏙(Qssok) 앱 > 문제 DB > 이어서 할 시험지

충전 후

충전했는데 앱에 ‘무료 키’ 표시가 그대로 있음추출을 이어 하면 자동으로 사라짐 · API 키 화면의 결제 등급이 Tier 1이면 정상
